# MANDATORY ROBINHOOD MCP LIVE PORTFOLIO REVIEW & AUDIT RULE

## Executive Directive
Whenever the user requests **"review my portfolio"**, **"portfolio review"**, invokes **`/mcp:robinhood:portfolio-review`**, or asks to **"audit my portfolio"** / **"check my holdings"**, the assistant **MUST UNCONDITIONALLY EXECUTE** the live Robinhood MCP toolchain to pull real-time account data and generate an institutional performance and rebalancing report.

Relying on cached numbers, static assumptions, or conversational memory is **STRICTLY PROHIBITED**. The assistant MUST execute live tool calls on every review.

---

## 🔄 1. Mandatory 4-Step Robinhood MCP Tool Pipeline

Every portfolio review request MUST execute these four MCP tool operations in sequence:

1. **Step 1: Account Identification (`get_accounts`)**
   - Query all brokerage accounts.
   - Identify the primary default account (Margin Account `••••3782`) and any agentic trading account (`••••6246`).
   - Always mask account numbers in user-facing output (e.g. `••••3782`).

2. **Step 2: Portfolio Balance & Buying Power (`get_portfolio`)**
   - Retrieve authoritative real-time figures for:
     * `total_value` (Total Portfolio / Account Value)
     * `equity_value` (Total Stock & ETF Value)
     * `crypto_value` (Total Crypto Value)
     * `cash` (Liquid Uninvested Cash)
     * `buying_power.buying_power` (Authoritative spendable buying power)
   - Audit the **Liquid Cash Buffer**: If buying power is below $1,500, immediately flag a **🚨 Critical Dry Powder Deficit**.

3. **Step 3: Open Positions Audit (`get_equity_positions`)**
   - Fetch all open long and short equity positions for the target account.
   - Extract for each holding:
     * `symbol` (Ticker)
     * `quantity` (Total shares held)
     * `shares_available_for_sells` (Liquid sellable shares)
     * `average_buy_price` (Cost basis per share)

4. **Step 4: Real-Time Price Ingestion (`get_equity_quotes`)**
   - Call `get_equity_quotes` with the full list of symbols obtained in Step 3.
   - Extract:
     * `quote.last_trade_price` (Live execution price)
     * `quote.adjusted_previous_close` or `close.price` (Prior session close)
     * Calculate Daily Change %: `((Price - PrevClose) / PrevClose) * 100`
     * Calculate Current Market Value: `Quantity * Price`
     * Calculate Unrealized Gain/Loss $: `Current Value - (Quantity * Avg Buy Price)`
     * Calculate Unrealized Gain/Loss %: `((Price - Avg Buy Price) / Avg Buy Price) * 100`
     * Calculate Portfolio Weight %: `(Market Value / Total Portfolio Value) * 100`
