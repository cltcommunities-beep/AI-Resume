# Mandatory 6-Component Stock Analysis Standard Rule

EVERY stock analysis report generated in this workspace MUST strictly include all 6 of the following components in exact chronological sequence without exception:

1. 🚩 **Visual Candle Sequence Banner**
2. 📊 **Robinhood API 1-Week Candle Data Breakdown Table**
3. 📰 **Breaking Market Headlines Table**
4. 📅 **Weekly Market Moving Catalysts Table**
5. 🛡️ **4-Point Fundamental Strength Gate Audit Table**
6. 📊 **17-Column Master Executive Portfolio Readiness Table**

## Compliance & Enforcement
- No component may be omitted, abbreviated, or replaced.
- Column 2 in the 17-Column Table MUST format live execution price as `🚀 Live Execution Price ($XX.XX Wall St Value = Market Cap / Total Shares)`.
- All prices, metrics, and solvency formulas must be verified against live Robinhood API data.
- No unescaped LaTeX math characters (`$...$` or `$$...$$`) inside markdown tables or text.
